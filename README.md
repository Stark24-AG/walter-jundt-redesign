# Walter Jundt Redesign Prototype

Unverbindliches Redesign-Konzept für das Malergeschäft Walter Jundt in Huttwil.

## Inhalt

- Moderne One-Page-Struktur für Malerei, Lackiererei und Spritzarbeiten
- Klare Kontaktwege mit Telefon, Mobilnummer und E-Mail
- Referenzbereich basierend auf den öffentlich sichtbaren Referenzen der aktuellen Website
- Responsive Layout für Desktop und Mobile

## Hinweis

Dies ist ein inoffizieller Akquise-Prototyp. Er ist nicht die offizielle Website
von Walter Jundt. Verwendete Fotos sind Platzhalterbilder und sollten in einer
finalen Version durch echte Projektbilder ersetzt werden.
